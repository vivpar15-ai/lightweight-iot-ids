# Results and Discussion

## 1. Overview
This chapter presents the experimental results obtained from the implementation of a lightweight deep learning-based intrusion detection system for resource-constrained IoT environments. The experiments were conducted using two benchmark intrusion detection datasets: NSL-KDD and UNSW-NB15. A baseline one-dimensional Convolutional Neural Network (1D-CNN) model was first developed and evaluated on both datasets. After establishing the baseline performance, two lightweight optimization techniques were applied: TensorFlow Lite dynamic range quantization and 50% magnitude-based pruning.

The purpose of this evaluation was to examine the trade-off between intrusion detection performance and deployment efficiency. The detection performance was measured using accuracy, precision, recall, and F1-score. The efficiency of the models was measured using model size and inference time. These metrics align with the research objective of developing an IDS model that maintains strong detection performance while reducing computational and storage requirements for resource-constrained IoT devices.

The experimental results were saved in reproducible CSV files and visualized using comparison plots. The main result table compares the baseline CNN, dynamic quantized TensorFlow Lite CNN, and 50% magnitude-pruned CNN models across both datasets.

## 2. Baseline CNN Model Performance
The baseline CNN model was developed to provide a reference point for evaluating the effectiveness of lightweight optimization techniques. The model was trained and evaluated separately on the processed NSL-KDD and UNSW-NB15 datasets. The same general CNN architecture was used for both datasets to ensure a fair comparison.

On the NSL-KDD dataset, the baseline CNN achieved an accuracy of 76.61%, precision of 96.02%, recall of 61.45%, and F1-score of 74.94%. The high precision indicates that when the model classified traffic as an attack, it was usually correct. However, the lower recall shows that the model missed a noticeable number of attack samples. This is important in an IDS context because false negatives can allow malicious traffic to remain undetected.

On the UNSW-NB15 dataset, the baseline CNN achieved stronger performance, with an accuracy of 92.23%, precision of 96.10%, recall of 92.33%, and F1-score of 94.18%. Compared with NSL-KDD, the UNSW-NB15 result shows a better balance between precision and recall. This suggests that the CNN model was more effective at distinguishing normal and attack traffic in the processed UNSW-NB15 dataset.

In terms of efficiency, the baseline CNN model size was 0.489 MB for NSL-KDD and 0.536 MB for UNSW-NB15. The inference time was 2.750 seconds for NSL-KDD and 14.661 seconds for UNSW-NB15. These baseline values provide the reference for measuring the effectiveness of quantization and pruning.

## 3. Dynamic Quantization Results
Dynamic range quantization was applied to the trained baseline CNN models and the models were converted into TensorFlow Lite format. This optimization technique reduces the numerical precision of model weights, which can significantly reduce model size and improve inference efficiency. This is especially useful for resource-constrained IoT devices where storage capacity, memory availability, and processing power are limited.

For the NSL-KDD dataset, the dynamic quantized TensorFlow Lite CNN achieved an accuracy of 76.62%, precision of 96.04%, recall of 61.46%, and F1-score of 74.95%. These results were almost identical to the baseline CNN model. The baseline F1-score was 74.94%, while the quantized model achieved 74.95%. This shows that quantization did not negatively affect the detection performance on NSL-KDD.

The efficiency improvement was more significant. The NSL-KDD baseline model size was reduced from 0.489 MB to 0.046 MB, representing a size reduction of 90.52%. The inference time decreased from 2.750 seconds to 0.579 seconds, giving an inference time improvement of 78.95%. This indicates that dynamic quantization was highly effective in reducing both storage requirement and inference time.

For the UNSW-NB15 dataset, the dynamic quantized TensorFlow Lite CNN achieved an accuracy of 92.23%, precision of 96.10%, recall of 92.33%, and F1-score of 94.18%. This was also almost identical to the baseline CNN, which had an F1-score of 94.18%. Therefore, the quantized model preserved the detection performance of the original baseline model.

The UNSW-NB15 model size was reduced from 0.536 MB to 0.050 MB, representing a size reduction of 90.62%. The inference time decreased from 14.661 seconds to 3.677 seconds, which corresponds to an inference time improvement of 74.92%. These results show that TensorFlow Lite dynamic range quantization is the most effective optimization technique tested in this stage for improving deployment efficiency while maintaining detection performance.

Overall, dynamic quantization produced the strongest lightweight improvement. It reduced model size by approximately 90% on both datasets and significantly reduced inference time without reducing accuracy, precision, recall, or F1-score. This result directly supports the thesis objective of developing a lightweight IDS model suitable for resource-constrained IoT environments.

## 4. Magnitude-Based Pruning Results
Magnitude-based pruning was applied to the trained CNN models by removing 50% of the low-magnitude weights. The purpose of pruning was to reduce model complexity by eliminating weights that contribute less to the model output. Unlike dynamic quantization, pruning keeps the same model architecture but increases sparsity by setting selected weights to zero.

For the NSL-KDD dataset, the 50% magnitude-pruned CNN achieved an accuracy of 76.48%, precision of 96.26%, recall of 61.05%, and F1-score of 74.71%. Compared with the baseline CNN F1-score of 74.94%, the pruned model showed a small decrease in F1-score. However, the performance reduction was minor, which suggests that many low-magnitude weights were not essential for the model's detection ability.

The NSL-KDD pruned model size decreased from 0.489 MB to 0.184 MB, representing a size reduction of 62.40%. The inference time decreased slightly from 2.750 seconds to 2.601 seconds, which corresponds to an inference time improvement of 5.42%. This shows that pruning reduced the stored model size but did not substantially improve inference speed.

For the UNSW-NB15 dataset, the 50% magnitude-pruned CNN achieved an accuracy of 92.82%, precision of 95.47%, recall of 93.92%, and F1-score of 94.69%. This was slightly higher than the baseline CNN F1-score of 94.18%. The improvement suggests that pruning may have removed less useful weights and slightly improved generalisation on the UNSW-NB15 dataset.

The UNSW-NB15 pruned model size decreased from 0.536 MB to 0.199 MB, representing a size reduction of 62.77%. However, the inference time changed only slightly, from 14.661 seconds to 14.605 seconds, giving an improvement of only 0.38%. This indicates that although pruning reduced the model size, it did not significantly improve inference time in the current implementation.

Overall, magnitude-based pruning was effective in reducing model size while maintaining acceptable detection performance. However, its inference time improvement was limited compared with dynamic quantization. This is likely because the pruned Keras models were still executed as dense models, meaning that zero-valued weights did not automatically result in proportional computational savings during inference.

## 5. Comparison of Lightweight Optimization Techniques
The experimental results show that both dynamic quantization and magnitude-based pruning reduced model size while maintaining acceptable intrusion detection performance. However, dynamic quantization provided stronger efficiency improvements overall.

For NSL-KDD, the baseline CNN achieved an F1-score of 74.94%, while the dynamic quantized TensorFlow Lite model achieved 74.95%. This shows that quantization preserved detection performance. The 50% pruned CNN achieved an F1-score of 74.71%, which was slightly lower than the baseline but still close. In terms of model size, quantization reduced the model from 0.489 MB to 0.046 MB, while pruning reduced it to 0.184 MB. Therefore, quantization produced a larger size reduction than pruning. The inference time also improved more strongly with quantization, decreasing from 2.750 seconds to 0.579 seconds. Pruning reduced inference time only slightly, from 2.750 seconds to 2.601 seconds.

For UNSW-NB15, the baseline CNN achieved an F1-score of 94.18%. The dynamic quantized TensorFlow Lite model also achieved approximately 94.18%, showing that quantization preserved detection performance. The 50% pruned CNN achieved a higher F1-score of 94.69%, suggesting that pruning slightly improved generalisation for this dataset. However, quantization still provided the best efficiency improvement. The model size decreased from 0.536 MB to 0.050 MB with quantization, compared with 0.199 MB after pruning. The inference time decreased from 14.661 seconds to 3.677 seconds with quantization, while pruning only reduced it to 14.605 seconds.

Overall, dynamic quantization was the most effective method for deployment efficiency. It produced approximately 90% model size reduction on both datasets and reduced inference time by 78.95% for NSL-KDD and 74.92% for UNSW-NB15. Pruning reduced model size by more than 60%, but the inference time improvement was limited. This suggests that pruning alone may not provide major runtime benefits unless it is combined with sparse-aware inference libraries, hardware acceleration, or further compression techniques.

The best model depends on the evaluation criterion. For NSL-KDD, the dynamic quantized TensorFlow Lite CNN was the best overall model because it achieved the best F1-score, smallest model size, and fastest inference time. For UNSW-NB15, the 50% pruned CNN achieved the highest F1-score, but the dynamic quantized TensorFlow Lite CNN had the smallest model size and fastest inference time. Therefore, dynamic quantization is the most suitable method for resource-constrained deployment, while pruning may be useful when the priority is to maintain or improve detection performance.

## 6. Discussion in Relation to Research Questions
The first research question asked how efficient deep learning-based IDS models can be designed for resource-limited IoT devices. The results show that a 1D-CNN can be used as a baseline IDS model for structured network traffic data, and lightweight optimization techniques can reduce the deployment cost of the model. By applying TensorFlow Lite dynamic quantization, the model size and inference time were significantly reduced without reducing detection performance. This indicates that CNN-based IDS models can be adapted for resource-constrained environments when appropriate optimization methods are used.

The second research question focused on how computational complexity and model size can be minimized while preserving high detection accuracy. The results show that dynamic quantization was highly effective for model size reduction, reducing the model size by approximately 90% on both datasets. Magnitude-based pruning also reduced model size by more than 60%. Importantly, the optimized models maintained similar F1-scores to the baseline models. This demonstrates that model size can be reduced substantially without major loss of intrusion detection performance.

The third research question considered the trade-off between efficiency and detection performance. The results show that dynamic quantization had the best trade-off because it reduced model size and inference time while preserving accuracy, precision, recall, and F1-score. Pruning also reduced model size, but its inference time improvement was small. On UNSW-NB15, pruning slightly improved F1-score, showing that pruning can sometimes improve generalisation. However, from a deployment perspective, dynamic quantization produced the strongest overall efficiency benefit.

The fourth research question asked how the lightweight IDS model compares with the conventional baseline deep learning IDS model. Compared with the baseline CNN, the dynamic quantized TensorFlow Lite CNN achieved almost identical detection performance with a much smaller model size and faster inference time. The pruned CNN also maintained comparable performance with reduced model size. Therefore, the lightweight models provide better deployment suitability than the baseline CNN, especially for IoT environments where memory, storage, and processing resources are limited.

## 7. Summary
This chapter presented the experimental results for the baseline CNN and two lightweight optimization techniques: dynamic quantization and magnitude-based pruning. The baseline CNN provided the reference performance on NSL-KDD and UNSW-NB15. Dynamic quantization reduced the model size by approximately 90% on both datasets and significantly improved inference time while maintaining almost identical detection performance. Magnitude-based pruning reduced model size by more than 60% and maintained acceptable F1-score, but it did not significantly improve inference time.

The results indicate that TensorFlow Lite dynamic quantization is the most effective optimization method tested in this study for lightweight IDS deployment. It achieved the best balance between detection performance, model size, and inference speed. These findings support the overall thesis objective of developing a lightweight deep learning IDS suitable for resource-constrained IoT devices.
